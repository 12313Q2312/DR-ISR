## 先测到的真实问题

普通 GP 基线试验为 5 任务 × 3 种子、每次 1200 求值单位。约 **23.11%** 子代与选中父代相同，约 **2.45%** 子代降低父代 MSE。15 次中 9 次测试 MSE < 1e-10。搜索时间合计约 1.68 秒，其中变异/交叉阶段约 1.03 秒，适应度阶段约 0.47 秒。

因此，在这些小数据任务里，低有效改动比例值得研究；“适应度计算是主要耗时瓶颈”并未成立。不能事先声称残差引导必然节省时间。阶段计时有少量仪器开销，且不包含所有搜索管理成本。

## 固定配置主实验：150 次

5 个任务 × 10 个搜索种子 × 3 组；每次总计 3000 个训练集向量求值单位，共 450000 单位。单进程顺序执行，组别顺序按任务/种子固定打乱。累计搜索时间约 31.71 秒，不含测试、画图和报告。

下表为独立插值测试 MSE 中位数，越低越好；极小数视为浮点精度附近，不声称数学恒等恢复。完整 IQR、配对差、外推与运行时间见 [原始报告](../evidence/benchmark-v1/report.md)。

| 任务 | 普通 GP | 残差引导 | 残差引导对 GP 胜/平/负 |
|---|---:|---:|---:|
| 多项式 | 0.00012997 | 0.00022820 | 5 / 2 / 3 |
| 加性 | 0.011343 | 0.095099 | 2 / 3 / 5 |
| 交互 | 约 1.86e-33 | 0.10594 | 1 / 1 / 8 |
| 复合 | 0 | 0 | 0 / 6 / 4 |
| 带噪训练的加性 | 0.00066968 | 0.050297 | 3 / 2 / 5 |

50 组配对结果合计 **11 胜、14 平、25 负**（绝对差阈值 1e-12）。多项式任务中位数与配对胜负指向并不完全一致，说明种子分布很不稳定，不能只选一种统计数讲故事。测试 MSE < 1e-10 的次数：GP **29/50**，残差引导 **16/50**，置乱对照 **13/50**。这些是数值命中，不能等同严格公式恢复。

残差引导每次通常只执行约 680 个完整表达式适应度评价；其余预算用于约 1850 个供体探针和约 464 个上下文计算。普通 GP 可执行 3000 个完整评价。按全部运行汇总，残差引导的子代改进比例约 5.24%，高于 GP 的约 1.31%，但它生成的子代总量少得多，而且约 48.19% 的子代仍与父代相同。这个局部比例不是有效性证明。

跨任务合计的单次搜索时间中位数为 GP 约 0.253 秒、残差引导约 0.129 秒、置乱约 0.149 秒。引导组更快同时误差往往更高，不能描述为“相同精度下加速”。小供体探针的成本低于完整树，当前统一计费很保守。节点×样本工作量和时间已保留，后续还需固定时间预算/节点工作预算对照。

## 怎么做的

1. 用不可变表达式树表示公式，所有方法复用同一套 `+,-,*,保护除法,sin,cos`，没有预置平方/四次项答案。平方必须由乘法组合出来。
2. 普通 GP 通过锦标赛选父代，随机交叉/变异，按训练 MSE + 节点惩罚更新种群。
3. 引导版本在交叉时比较少量候选供体。先求训练残差 `r`，再用外层敏感度 `J` 估计替换带来的输出改动 `delta=J*(t-s)`，用 `mean(2*r*delta-delta²)` 排序。
4. 选中后仍完整计算子代真实训练误差；估计可能错。测试数据从不参与搜索。
5. 置乱组打乱残差与样本的对应关系，帮助检查残差对齐信息是否有用，避免把额外筛选本身算成算法贡献。

## 演示验收步骤

1. 双击打开 [离线演示](../evidence/benchmark-v1/demo.html)。不需要网络、账户或运行训练。
2. 选择“交互”任务、种子 1：普通 GP 测试误差约为浮点精度，残差引导的 `sin(sin(x0))` 丢掉了交互项，MSE 约 0.10594。对照表同时显示其计算次数。
3. 选择“复合”任务、种子 0：三组均得到 `sin(x0*x0)`。这说明当前表示支持内外层串联，不能证明只有新机制能得到它。
4. 选择“复合”任务、种子 2：残差引导给出 `sin(x0)*x0`，测试 MSE 约 0.00014445，外推 MSE 约 **1.5183**；普通 GP 得到目标结构。这展示小区间拟合与结构正确性的区别。
5. 移动页面下方输入滑块：观察内层平方、外层正弦，以及外层敏感度 `cos(g)` 的变化。这部分是机制解释，不是另一个训练实验。
6. 复核：在仓库目录执行 `python verify_evidence.py evidence/benchmark-v1`；重新实验执行 `python run.py`。新结果保存在独立时间戳目录。

## 本版边界与下阶段判断

本版采用单一数据划分和小型合成任务，只测搜索随机性；没有显著性检验、现代 SR 方法对照或真实数据验证。复合任务区间较窄，普通 GP 已容易解出，不足以检验复杂深层结构。测试指标看过后没有据此调参再跑本版主实验。

建议下一步优先解决引导组高重复率和探针预算效率，再开展材料提出的“残差诊断改变生成概率”与“中间坐标记忆”两个独立消融。两个可训练神经元串联需要另立实验，明确中间监督、联合训练或交替训练以及可辨识性问题。未经实验，不声称这些方向一定奏效。

当前没有 GPU、付费 API 或新数据资源需求。本项目留下可复用树接口、上下文导数、预算账本、成对实验、数据格式、失败案例和回放验证；它们可直接服务下一轮机制实验。用户不需要先读懂全部实现才能验收，后续可从修改一个目标函数、预测结果、亲手运行并解释一张图开始建立自己的掌握。
