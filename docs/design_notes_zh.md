# 你的想法如何进入项目

## 已实现的边界

第一版验证“普通表达式树 GP + 残差引导的子树选择”。它能表示乘法和任意允许深度内的复合结构，但没有训练神经网络，也没有实现整套增量式 DR-ISR。

你提出的两个神经元串联：`x → g(x) → h(g(x))`，先作为**符号模块**理解。例如内层子树 `g=x*x`、外层上下文 `h=sin`。当前实现用链式法则估计内层改动的影响，且包含 `sin(x²)` 任务。表示得出这种结构，不等于已经证明搜索一定找得到它，更不等于已验证两神经元训练的优势。后续若接入真正的可训练神经元，需要另外定义参数、损失、优化方式与对照。

## 借鉴你提供的 DR-ISR 材料

保留两个待检验方向：

1. 诊断残差的依赖、对称、振荡特征，调整算子/变量采样概率；保留随机探索概率。
2. 区分“直接进入输出的模型项”和“未来参与复合的中间坐标”；为工作记忆设容量、去重、淘汰和展开复杂度限制。

建议后续因子实验：普通 GP；只加残差诊断；只加记忆；两者都加。两边必须共享允许的原子运算符与可达表达式空间，所有探针、变量对扫描、局部拟合和回代成本都要记账。复用本版数据、树表示、随机种子、预算日志和报告接口；这就是本次投入留下的可复用资产。

## 材料中需要修正的地方

- 原偶对称分数 `||r+flip(r)||²/(2||r||²)` 的范围为 [0,2]，完全偶对称时等于 2。改成分母 `4||r||²` 才在 [0,1]。直接 clip 到 1 会把不同程度的偶对称压成同分。
- 分位数反转不是普适的 `u → -u`。只有采样关于零对称、配对合理，且处理其他变量和噪声后，才可解释为奇偶性证据；排序统计也不能保证判断函数形式。
- 分箱解释方差是**条件均值依赖**的估计，不是互信息。它会有有限样本上偏，固定分箱会漏掉高频结构；不保证对任意确定关系都接近 1。应有置乱对照或独立样本检查。
- 过零次数依赖输入范围、采样密度、平滑窗口和噪声。`sin(z)` 在有限区间内可以只有少数过零，不能靠“过零≥3”可靠识别全部周期结构。
- 对称分布下 `z` 与 `cos(z)` 的总体线性相关为零，样本相关仍可非零；混合项、相关输入和不对称采样会改变结论。
- 节点数替代 BIC 的参数数目，更适合叫**受 BIC 启发的复杂度分数**，不能自动获得标准 BIC 的理论解释。回代剪枝不能保证“彻底解决”早期错误和局部最优。
- 提供的示例代码没有普通 GP 对照，只统计了生成候选次数；诊断中反复求值、交互扫描、回代和剪枝未计入。不可据此认定“100 次相当于 GP 数万次”或“已精确恢复”。
- 原材料的创新边界表述过强。语义 GP、语义反向传播、boosting 和条件生成已有大量工作，需继续做有证据的文献比对。

这些修正没有否定想法；它们把演示性叙述变成可反驳、可复现的实验假设。
